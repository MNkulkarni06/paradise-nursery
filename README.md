# Paradise Nursery

Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.

## Features
- Landing page with company name, description and a "Get Started" button
- Product listing page with 18 houseplants grouped into 3 categories (Air Purifying, Aromatic, Low Maintenance)
- "Add to Cart" buttons that disable after use and update the cart icon count
- Shopping cart page with quantity controls, per-item totals, overall total, delete buttons, a "Checkout" (Coming Soon) button and a "Continue Shopping" button
- Navbar with Home, Plants and Cart links on the product and cart pages

## Tech Stack
React, Redux Toolkit, React-Redux, Vite

## Run Locally
```
npm install
npm run dev
```
